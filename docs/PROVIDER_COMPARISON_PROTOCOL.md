# Supplemental provider comparison: final measurement protocol

Research window: official Employment Situation and Consumer Price Index releases dated January–September2026. Observation periods run December2025–August2026. Original project information cutoff remains13October2026; this retrospective supplement is acquired15October2026 and contains no post-September publication dates. It does not alter the original corpus, forecasts or300-item annotation pool.

The graph's operational measure is **same-event relative negative framing (percentage points)**. For provider p and release e, first average the binary pretrained classifier's negative label over eligible titles in that provider/event cell. Subtract the equal-weight mean of other included providers for that exact release. Average these differences equally over an identical common-event set for all displayed providers. Positive means a higher sampled negative-title share than sampled peers covering those same releases; negative means lower. Zero is the sampled-peer benchmark, not objective neutrality. Negative true statements and different legitimate release components can cause differences. This is not a factual, ideological, political or causal bias estimate, and it does not measure audience exposure.

Fixed queried panel: CNBC(cnbc.com), FoxNews(foxnews.com), FoxBusiness(foxbusiness.com), CNN(cnn.com), Reuters(reuters.com), AssociatedPress(apnews.com), NPR(npr.org), Bloomberg(bloomberg.com), WallStreetJournal(wsj.com). The final exploratory comparison requires the two requested brands, CNBC and Fox News, and at least six identical releases. Additional providers are admitted by mechanically choosing the largest common-support panel; ties follow the original provider order. No sentiment value enters support selection. All queried providers receive coverage rows; outside-panel providers receive no comparable bias bar. The initial six-brand mandatory core failed strict relevance review with only four common events. This coverage-only feasibility amendment, query refinement and review are fully documented in PROVIDER_PROTOCOL_AMENDMENT.md; the final design is not described as preregistered or unchanged since first retrieval.

Official primary calendar: https://www.bls.gov/schedule/2026/home.htm . Employment release dates: Jan9, Feb11, Mar6, Apr3, May8, Jun5, Jul2, Aug7, Sep4. CPI: Jan13, Feb13, Mar11, Apr10, May12, Jun10, Jul14, Aug12, Sep11. February's employment release was rescheduled toFeb11; use the published calendar rather than a first-Friday rule. Both series release at08:30Eastern; archive URLs are preserved. Two calendar dates are searched: release day and next day. RSS hours often default to07:00/08:00UTC, so publication is used at NewYork date precision only. Searches and date filters cannot certify that a title was posted after the intraday embargo or that the RSS carried the historical title then.

Identical final family queries across providers: labor `(payroll OR unemployment OR "jobs report" OR "job growth" OR "job gains" OR jobs OR hiring OR employment)`; CPI `("consumer price" OR CPI OR inflation)`. The added labor terms and preserved initial query are documented in PROVIDER_PROTOCOL_AMENDMENT.md. Each query adds the provider domain and the same release/result date bounds. Only source-element domains matching the named publisher are retained; article, live-update, video and opinion headline genres may be mixed because article bodies and reliable genre metadata are unavailable. Record all search caps, dates, errors, raw-response SHA256 and URLs. A maximum of100 ranked RSS candidates can be returned per provider/event query. This is an indexed convenience sample, not all output.

Before model scoring, keep titles with the correct event-family terms and completed-result wording or a numerical result. Exclude unambiguous previews, forecasts to future results, ADP/private-payroll-only reports, weekly claims, PCE/PPI stories in CPI windows, explicit foreign-only titles, physical/entertainment inflation, and clearly unrelated generic job references. An event-family/date match is a release-window proxy: headlines are not full-article verified as being exclusively about the same report. Topic components and headline angles can differ. Preserve exclusions and all retained evidence. Deduplicate normalized titles within provider/event; retain identical titles across providers and flag shared text. If more than20 eligible titles remain in a cell, choose20 by frozen SHA256 ID order independently of tone. No missing provider/event cell is filled, and no zero is substituted for missing coverage. The final narrow primary sample also applies the documented AI title-only relevance review. A positive review may resolve only the missing-result-anchor regex condition, never previews, market reactions, other metrics or multi-topic exclusions. Administrative publisher suffixes and a leading Watch prefix are removed from model inputs; exact canonical-title duplicates within provider/event are excluded without replacement. Raw text and all decisions are retained.

Model: fixed CardiffNLP RoBERTa sentiment revision3216a57f2a0d9c45a2e6c20157c20c49fb4bf9c7; source labels are omitted from model inputs. Dictionary sensitivity uses the same fixed VADER thresholds as the main project. Continuous P(negative), raw negative shares, event-only bootstrap intervals, one-title-per-cell hash sensitivity, family-specific differences, provider/event counts, cross-provider duplicate flags and publication-hour diagnostics accompany the main graph. Neither classifier has received human validation in this supplemental provider/domain sample; the original dual-AI diagnostic is not a substitute for human validation.

Uncertainty: fixed-seed5,000 bootstrap replicates, resampling release months as clusters and retaining both CPI and employment cells of each selected month together. Each replicate recomputes the event-equal estimator; months with only one common event retain that event. The 95% percentile ranges are conditional release-month resampling/stability summaries for this fixed release calendar, not guaranteed population confidence intervals. They reflect only observed event/month variation conditional on captured titles and fixed classifier labels. With at most nine month clusters, precision is limited; intervals exclude search-selection, labeling, measurement and within-cell sampling uncertainty. Event-cluster bootstrap is a sensitivity. Intervals are pointwise, not simultaneous, and are not a basis for selecting a winning provider. Show intervals even if wide; never draw unsupported bars for providers with insufficient common events.

Tests must verify common-event identity, equal provider/event weighting, no mixing of FoxNews/FoxBusiness domains, missing-cell exclusion, known publication-date scope, estimator zero-sum property, bootstrap clustering and interval sanity. A separate statistical audit will inspect actual support, duplicates and timing after acquisition.


Final implementation follows the transparent feasibility and relevance amendments in PROVIDER_PROTOCOL_AMENDMENT.md. The original six-provider mandatory core is not silently treated as feasible: it has only four strictly supported common events. The final exploratory chart requires CNBC/Fox News, chooses the largest remaining provider panel with at least six common events using coverage only, and preserves all queried-provider coverage. The six-event threshold is unchanged. Bootstrap intervals are conditional release-month resampling/stability ranges for a fixed calendar, not guaranteed population confidence intervals.
